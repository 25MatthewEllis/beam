# Beam Designer

Beam Designer is a Tkinter desktop app for educational, preliminary analysis of
simply supported, cantilever, and overhanging beams. It calculates support
reactions, shear, moment, deflection, and basic comparisons, with beam inputs,
CSV results export, and a calculation-sheet PDF.

## Requirements

Python 3 with Tkinter. The app uses only the Python standard library; no
additional packages need to be installed.

## Run

From the project directory:

```sh
python3 beam_designer.py
```
